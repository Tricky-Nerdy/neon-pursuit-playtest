These Blender renders inspect live Godot scene geometry exported by tests/export_geometry.gd:

- map.png: complete irregular coastline, four connected circuits and sculpted terrain
- road.png: waterfront driving scale
- city.png: detailed city blocks
- canyon.png: inner canyon route
- ridge.png: northern mountain section

They are NOT Godot gameplay screenshots. UI, Label3D text, the water shader and engine lighting are not reproduced. Use tests/render_capture.gd on a machine with a graphics display for actual gameplay captures.
